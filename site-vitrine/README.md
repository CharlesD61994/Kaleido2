# Site vitrine Atelier Kaleido

Première maquette statique du site public Atelier Kaleido.

## Fichiers

- `index.html`: structure de la page.
- `styles.css`: identité visuelle, couleurs, halos, cartes, sections.
- `app.js`: petites interactions de base.

## Comment tester

Ouvrir directement:

```text
site-vitrine/index.html
```

Ou lancer un petit serveur local depuis le dossier du projet:

```bash
npx serve site-vitrine
```
